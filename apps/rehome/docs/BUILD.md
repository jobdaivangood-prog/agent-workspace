# Сборка и проверка

Собирайте из каталога `apps/rehome` на Windows x64. Нужны доверенный Python 3.12 и штатный C# compiler `%SystemRoot%/Microsoft.NET/Framework64/v4.0.30319/csc.exe`. Ничего не устанавливается в систему, реальный профиль Codex не читается.

```powershell
python scripts/build_release.py --output output/build-0.1.41-beta.1
$env:REHOME_TEST_DECODER=(Resolve-Path output/build-0.1.41-beta.1/build-tools/libzstd.dll).Path
python scripts/run_tests.py
```

Сборщик проверяет закреплённые SHA256 двух upstream-архивов, извлекает только обычные файлы с допустимыми путями, сохраняет notices и формирует отдельный сокращённый Python runtime. При необходимости укажите `--cache ПАПКА` с уже загруженными архивами: проверки хешей сохраняются.

Переменная `REHOME_TEST_DECODER` направляет синтетические проверки сжатых журналов на DLL из проверенной поставки. Без неё эти проверки будут явно пропущены, если DLL не подготовлена в `output/test-deps/`.

Публичный состав модулей задан в `resources/app-modules.json`; автоматического включения всех Python-файлов каталога нет. В runtime не попадают пользовательские настройки, профили, копии, SSH-ключи, отчёты частных проверок или `codex.exe`.

Пустые базы создаются из `schema-spec.json`; проверяются состав схемы, служебные миграции и отсутствие пользовательских записей. `Program/manifest.json` фиксирует все включённые файлы. Хеш этого манифеста встраивается в запускатель; изменение кода или runtime блокирует запуск.

`ReHome.exe --check` проверяет запускатель и компоненты без открытия рабочего профиля. Отсутствующие шаблон и decoder проверяются при конкретном действии, чтобы не лишать доступа к откату. Для отката используются отдельный закреплённый план транзакции и ожидание закрытия Codex.

`build-info.json` описывает именно новую сборку. Успешные исходные тесты не заменяют проверку полученного ZIP и фактический прогон на втором ПК. Перед публикацией сверяются архив, запускатель, режим восстановления и откат, а статусы обновляются только по полученным результатам.

Сборки намеренно создаются в новых каталогах и получают новые UUID/временные метки. Функциональная воспроизводимость и проверка исходных поставок предусмотрены; идентичность ZIP по байтам между двумя независимыми сборками не обещается.

## Шаблон CI

В `ci/rehome-tests.yml` сохранён готовый шаблон GitHub Actions с закреплёнными версиями actions. В этом выпуске он не активирован: подключение публикации не имеет разрешения `workflow`. Приложение и инструкция от этого не зависят; фактически выполненные проверки перечислены в `VALIDATION.md`.
