# Совместимость и ограничения ReHome

## Статус пакета

Архив Windows x64 называется `ReHome-0.1.40-beta.1-windows-x64.zip` и размещается в [выпуске ReHome](https://github.com/jobdaivangood-prog/agent-workspace/releases/tag/rehome-v0.1.40-beta.1). Доказательства проверки именно этого архива приведены в [VALIDATION.md](VALIDATION.md).

## Поддерживаемая среда

| Компонент | Требование |
| --- | --- |
| Windows | Windows 10/11 x64 |
| Codex | Только `0.166.0-alpha.5.1` |
| SHA-256 исполняемого файла Codex | `3097c909fb6d5cd63510d44aceb1d42df9f6e85722a3e447e477def1ecf60e16` |
| Python | Пользовательская установка не нужна; runtime включён в комплект и проверяется приложением |
| Папка приложения | Локальная папка вне Synology Drive/OneDrive |
| Папка копий | Локальный диск или папка Synology Drive |

Неизвестные и отличающиеся версии Codex отклоняются. ReHome не выбирает другую версию автоматически. Не переименовывайте и не подменяйте исполняемый файл Codex, чтобы обойти проверку.

## Границы переноса

| Данные | Поведение |
| --- | --- |
| Видимые сообщения пользователя и ассистента | Переносятся вместе с текстом и порядком |
| Даты и проекты | Сохраняются в пределах проверенной истории источника |
| Обычные и архивные чаты | Входят в историю копии |
| Готовые файлы проектов | Только если пользователь явно выбрал каждый файл |
| Подходящие skills и agent definitions | Копируются как подготовленные ресурсы; автоматическая активация не обещается |
| Исходники и невыбранные результаты | Не копируются |
| Структурированные вложения | Не переносятся; текстовые описания остаются частью видимого текста |
| Reasoning и tool payload | Не копируются |
| Авторизация и активные настройки Codex/MCP | Остаются локальными и не переносятся |
| Плагины | Требуют отдельной официальной установки и настройки на целевом ПК |

Архивы копий содержат обычные данные и не шифруются ReHome. Учитывайте это при выборе папки и доступа к ней; при использовании синхронизации применяются настройки выбранного сервиса.

## Откат и данные после восстановления

Откат возвращает состояние до восстановления при закрытом Codex. Данные, созданные после восстановления, сохраняются отдельно, а не стираются вместе с возвращаемым профилем. Перед повторной операцией дождитесь завершения отката и проверьте обе группы данных.
