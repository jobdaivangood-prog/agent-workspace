# Начало и окончание работы

Новый режим ReHome переносит проекты и карточки чатов со сводками, последние готовые результаты и поддержанные материалы среды. Полная прежняя переписка в сводку не входит. При создании копии исходный профиль не изменяется; при восстановлении прежнее состояние сохраняется для отката.

## Включение

1. Распакуйте полный комплект ReHome в обычную локальную папку на каждом ПК. Само приложение не запускайте из Synology Drive.
2. Откройте ReHome, выберите папку копий и нажмите **«Включить команды „Начни / Закончи работу“»**. Старый блок команд Agent Workspace заменяется одним обработчиком ReHome; прежний файл правил сохраняется рядом с программой в `AgentRulesBackups`. Другие правила и база Workspace остаются на месте.
3. Перезапустите Codex. На втором ПК выберите соответствующую локальную папку Synology Drive с теми же публикациями.

Отдельно устанавливать Python, новую модель или MCP не нужно. Сводки составляет агент внутри Codex до завершения приложения. При первом сохранении большого количества чатов чтение и подготовка сводок могут занять заметное время.

## Закончить работу

Напишите в Codex **«Закончи работу»**. Агент проверит каталог, прочитает доступную историю, сохранит цель, итог, решения с краткими основаниями, ограничения и следующие действия. Для каждого логического результата выбирается последняя выданная версия; одноимённые разные результаты не объединяются. Рабочие исходники проекта автоматически не копируются.

Затем запускается независимый помощник. Он запрашивает штатное закрытие Codex/ChatGPT, ждёт завершения писателей, собирает пакет и проверяет его. Помощник запускается от текущего пользователя через одноразовую задачу Windows без расписания, пароля и повышения прав; после завершения регистрация задачи удаляется. Принудительного завершения процессов нет.

После подготовки сводки в чате могут появиться новые сообщения. Такие сообщения отмечаются как не включённые, а сводка — как неполная. Если изменились уже прочитанные сообщения, сборка останавливается до обновления подготовки. Запуск помощника ещё не означает, что копия создана: результат определяется выходным JSON и HTML-отчётом.

В отчёте: обнаружено / включено / пропущено / ошибки / ожидают по чатам, проектам, готовым файлам, навыкам, агентам, плагинам и настройкам. Недостающие файлы не восстанавливаются из текста ссылки: они перечисляются с названием проекта/чата и причиной. Неполные сводки также отмечаются. Ресурсы плагинов и настройки могут переноситься как материалы для местной настройки, без автоматической активации.

## Начать работу

Дождитесь загрузки файлов Synology на принимающий ПК и напишите **«Начни работу»**. ReHome проверит полученные публикации и применит последнюю полную. Если публикация уже установлена, повторного восстановления не будет, а местное продолжение сохранится.

Если на двух ПК работа разошлась, действует выбранная политика: применяется последняя полученная публикация; прежнее местное состояние сохраняется для отката. Порядок определяется логическим номером публикации. Для одновременных публикаций применяется стабильное сравнение идентификаторов устройств и публикаций. Это обеспечивает одинаковый выбор при одинаковом наборе файлов, но не доказывает физическую хронологию работы отключённых ПК. Публикацию, ещё не доставленную Synology, ReHome увидеть не может.

Перед изменением профиля Codex закрывается штатно; после успешной установки открывается снова. Проекты, обычные и архивные чаты восстанавливаются как карточки со сводками. Последние результаты находятся в новых локальных папках, а ссылки в сформированном разделе результатов ведут на эти файлы. Канонические идентификаторы сохраняются при следующих переносах и переименованиях.

## Откат и старые копии

При неудачной операции не начинайте новое восстановление поверх незавершённого. Откройте ReHome и нажмите **«Вернуть прежнее состояние»**. Перед откатом приложения должны быть закрыты; данные, созданные после восстановления, сохраняются отдельно.

Кнопки **«Создать бекап»** и **«Восстановить бекап»** продолжают работать с полным видимым текстом истории и прежними форматами. Новый режим команд использует отдельный формат сводок. Для публикации нового режима выбирается автоматически полностью полученный пакет внутри `ReHome-ID/Package`; пользователю не нужно вручную выбирать вложенные папки.

## Что не обещается

- Точное восстановление исходной переписки из краткой сводки.
- Перенос отсутствующих файлов, секретов и авторизации.
- Автоматическая работа всех плагинов и настроек другого ПК без местной проверки.
- Доставка Synology, пока пакет создан только локально.
- Исправление всех старых непереносимых ссылок внутри произвольного текста; готовые результаты получают отдельный проверяемый список ссылок.

Существующая база Agent Workspace и её выбранные ревизии автоматически не изменяются. Источник продолжения нового режима — самодостаточная публикация ReHome. Подходящие прежние handoff могут использоваться агентом как проверенный материал для сводки.
