# Сторонние компоненты ReHome

Уведомление `COPYRIGHT` относится к оригинальному коду и ресурсам ReHome. Оно **не заменяет и не ограничивает** лицензии сторонних компонентов, перечисленных ниже.

## Python и нативные зависимости

Встроенный Python 3.12.16 / Windows x86-64 MSVC берётся из [python-build-standalone, выпуск 20261026](https://github.com/astral-sh/python-build-standalone/releases/tag/20261026).

- Архив: `cpython-3.12.16+20261026-x86_64-pc-windows-msvc-pgo-full.tar.zst`.
- SHA256: `37b4eb2818fee605fefa75ed156c4f2e1aaeaebaf662f9b30177c842ee16c48f`.
- Контрольная сумма сверена с `digest` опубликованного GitHub asset. Это не заявление о проверке цифровой подписи.
- Нативные файлы не изменяются. Каждый включённый `.exe`, `.dll` и `.pyd` сравнивается с соответствующим файлом этого архива.

Полные notices сохранены в `third_party/` и в `Program/Runtime/licenses/` готового приложения. Они охватывают CPython, Tcl/Tk 8.6.15, libffi, SQLite, bzip2, liblzma, Expat, mpdecimal, zlib и другие библиотеки исходной поставки. Часть исходных notices может относиться к компонентам, которые не включены в сокращённый runtime.

**Microsoft runtime:** полный `python-WINDOWS-NOTICES.txt` сохраняет условия Microsoft Distributable Code для VC runtime. Эти файлы входят в поставку интерпретатора Python; они не предоставляются как отдельный универсальный пакет Microsoft Redistributable. Применяются условия из этого уведомления, а не `COPYRIGHT` ReHome.

Преобразования при сборке: стандартная библиотека упаковывается в ZIP; тесты, pip/site-packages, venv, IDLE и демонстрационные материалы исключаются; добавляется изолирующий `python312._pth` без `import site`. Tcl/Tk scripts и нативные бинарники копируются без изменения. Полные версии, исходные URL и контрольные суммы приведены в `third_party/source-evidence.json`.

## Zstandard

`libzstd.dll` 1.5.7 взята из [официального выпуска facebook/zstd v1.5.7](https://github.com/facebook/zstd/releases/tag/v1.5.7), архив `zstd-v1.5.7-win64.zip`.

- SHA256 архива: `acb4e8111511749dc7a3ebedca9b04190e37a17afeb73f55d4425dbf0b90fad9`.
- SHA256 DLL: `8f07e1112ed283e5cd2798833e9a3c32d8961381bc36da04af57a1b0ca9bd40b`.
- Лицензия: BSD, полный текст — `third_party/LICENSE-zstd.txt` и `Program/Dependencies/LICENSE-zstd.txt`.

Для этого старого GitHub asset поле digest издателя отсутствует. Указанные SHA256 вычислены из загруженной поставки; они не выдаются за подпись или аттестацию издателя. Консольный zstd используется только при сборке и не входит в приложение.

## Интерфейс со схемой Codex

Codex устанавливается отдельно; его исполняемый файл не включается. Пустой шаблон схемы получен из изолированного нативного запуска точного поддерживаемого движка. В публичном JSON содержатся определения объектов SQL и служебные миграции, пользовательские таблицы пусты. В каждом выпуске файлы SQLite создаются заново.

Открытый проект [openai/codex](https://github.com/openai/codex) использует Apache-2.0; соответствующий текст сохранён в `third_party/LICENSE-codex-apache.txt` как уведомление для связанного upstream-материала. Это не меняет условия оригинального адаптера ReHome.

## Повторно используемый сборщик

Файлы `src/vendor/codex_backup/backup.py` и `password_prompt.py` — ранее созданные пользователем вспомогательные модули. В публичной копии заменён только машинный путь по умолчанию в отдельной CLI-команде; повторно используемые функции не менялись. Происхождение, исходные и текущие SHA256 зафиксированы в соседнем `provenance.json`; к этому оригинальному коду применяется `COPYRIGHT` ReHome.
