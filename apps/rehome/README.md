# ReHome

**Перенос работы Codex между Windows-ПК.** Режим 0.2 по командам «Закончи работу» и «Начни работу» переносит проекты, сводки чатов и выбранные готовые результаты с возможностью возврата прежнего состояния. Он переносит сводки, а не полную исходную переписку. Прежние кнопки полного бекапа сохранены как отдельный режим.

Новый режим описан в [инструкции по началу и окончанию работы](docs/SESSION-MODE.ru.md). Сначала включите команды по инструкции и перезапустите Codex. Затем выберите папку копий в ReHome и используйте «Закончи работу» на исходном ПК и «Начни работу» на целевом. Команда завершения подготавливает сводки; приложение помогает сохранить и восстановить выбранные данные. Копирование папки само по себе не подтверждает, что другой ПК получил или применил её.

## Быстрый старт

1. Скачайте `ReHome-0.2.0-beta.1-windows-x64.zip` из Releases.
2. Полностью распакуйте архив, например в `C:\Tools`, вне Synology Drive и OneDrive. Архив уже содержит папку `ReHome`.
3. Откройте `C:\Tools\ReHome\ReHome.exe` (или `ReHome.exe` внутри папки `ReHome` в выбранном месте распаковки). Python уже включён в комплект; сохраняйте рядом остальные файлы и папку `Program`.
4. Выберите папку копий — это может быть локальная папка Synology Drive.
5. Для режима команд после настройки и перезапуска Codex используйте «Закончи работу» и «Начни работу», следуя [порядку сессии](docs/SESSION-MODE.ru.md). Для прежнего режима полной видимой истории используйте кнопки **«Создать бекап»** и **«Восстановить бекап»**. Восстановление полной копии требует отдельной папки с именем, начинающимся с `ReHome-`: внутри неё находятся `manifest.json`, `ReHome.json`, `READY.json` и папка `Chats`. Для этого восстановления ReHome попросит вручную закрыть Codex; настольное приложение ChatGPT, если оно открыто, также нужно закрыть.

Архив приложения с GitHub не содержит личных бекапов. Они находятся в отдельно выбранной вами папке копий (обычно `Backups`); при переносе через Synology Drive сначала дождитесь полной загрузки копии на целевой ПК. Пример выбора папки приведён в [инструкции](docs/USER-GUIDE.ru.md#восстановить-копию).

Для возврата состояния перед восстановлением предусмотрена кнопка **«Вернуть прежнее состояние»**. Данные, появившиеся после восстановления, сохраняются отдельно.

Для переноса файлов из старой копии нажмите **«Найти файлы по ссылкам в копии»**, проверьте список, добавьте выбранные результаты и нажмите **«Создать копию с выбранными файлами»**. При восстановлении связанные Markdown-ссылки в сообщениях ассистента будут указывать на новые локальные файлы. Исходный текст остаётся в бекапе. Подробности, границы поддержки ссылок и польза штатной архивации чатов — в [инструкции по файлам](docs/FINISHED-FILES.ru.md).

## Что сохраняется

- Проекты, обычные и архивные пользовательские чаты, полный видимый текст user/assistant, порядок, статусы и даты.
- Цитаты исходных материалов и описания вложений внутри текста сообщений.
- Готовые файлы, которые пользователь **явно выбрал** и привязал к проекту.
- Поддержанные ресурсы навыков и определений агентов; материалы остальных компонентов среды для местной настройки.

Отдельные исходные вложения, изображения как объекты, скрытые рассуждения, служебные ответы инструментов и авторизация в копию не входят. Активные настройки MCP, плагины и авторизация требуют местной проверки; полная автоматическая активация среды не заявляется. Копия хранится обычными файлами без встроенного шифрования.

## Статус beta

Версия `0.2.0-beta.1` предназначена для **Windows 10/11 x64** и проверенного движка Codex **0.166.0-alpha.5.1**. Неизвестная версия отклоняется до применения данных. Точный SHA256 приведён в [описании совместимости](docs/COMPATIBILITY.md).

Здесь не заявляется подтверждённое завершение переноса режима 0.2 на втором физическом ПК. Область проверок и ограничения выпуска перечислены в [VALIDATION.md](docs/VALIDATION.md).

## Разработка и сборка

Нужны Windows x64, доверенный Python 3.12 и штатный C# compiler .NET Framework 4.x. Установка зависимостей через pip не требуется.

```powershell
python scripts/build_release.py --output output/build-0.2.0-beta.1
$env:REHOME_TEST_DECODER=(Resolve-Path output/build-0.2.0-beta.1/build-tools/libzstd.dll).Path
python scripts/run_tests.py
```

Сборщик получает Python и zstd из закреплённых публичных поставок, проверяет SHA256 и сравнивает каждый включённый PE-файл с исходной поставкой. Пользовательские профили, установленный Codex и прежние частные результаты сборки не читаются. Код Codex в комплект не включается. Пустые схемы строятся заново из `resources/schema-spec.json` и проверяются перед упаковкой.

Результат — `ReHome-0.2.0-beta.1-windows-x64.zip`, `SHA256SUMS.txt` и `build-info.json`. Каждая сборка получает собственный идентификатор и контрольные суммы; побайтовая воспроизводимость между сборками не обещается. Подробности — [BUILD.md](docs/BUILD.md).
