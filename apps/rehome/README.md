# ReHome

**Бекап и восстановление Codex для Windows.** Проекты, видимый текст переписок, порядок и даты — в проверяемой копии с возвратом прежнего состояния.

[Скачать приложение](https://github.com/jobdaivangood-prog/agent-workspace/releases/tag/rehome-v0.1.40-beta.1) · [Инструкция](docs/USER-GUIDE.ru.md) · [Совместимость](docs/COMPATIBILITY.md)

## Быстрый старт

1. Скачайте `ReHome-0.1.40-beta.1-windows-x64.zip` из Releases.
2. Полностью распакуйте архив в обычную локальную папку вне Synology Drive и OneDrive.
3. Откройте `ReHome.exe`. Python уже включён в комплект.
4. Выберите папку копий — это может быть локальная папка Synology Drive.
5. Нажмите **«Создать бекап»** или **«Восстановить бекап»** и следуйте статусу в окне. ReHome попросит полностью закрыть Codex вручную.

Для возврата состояния перед восстановлением предусмотрена кнопка **«Вернуть прежнее состояние»**. Данные, появившиеся после восстановления, сохраняются отдельно.

## Что сохраняется

- Проекты, обычные и архивные пользовательские чаты, полный видимый текст user/assistant, порядок, статусы и даты.
- Цитаты исходных материалов и описания вложений внутри текста сообщений.
- Готовые файлы, которые пользователь **явно выбрал** и привязал к проекту.
- Поддержанные ресурсы навыков и определений агентов; материалы остальных компонентов среды для местной настройки.

Отдельные исходные вложения, изображения как объекты, скрытые рассуждения, служебные ответы инструментов и авторизация в копию не входят. Активные настройки MCP, плагины и авторизация требуют местной проверки; полная автоматическая активация среды не заявляется. Копия хранится обычными файлами без встроенного шифрования.

## Статус beta

Версия `0.1.40-beta.1` предназначена для **Windows 10/11 x64** и проверенного движка Codex **0.166.0-alpha.5.1**. Неизвестная версия отклоняется до применения данных. Точный SHA256 приведён в [описании совместимости](docs/COMPATIBILITY.md).

Проверенный цикл переноса между двумя ПК включал 18 проектов, 85 чатов и 3798 сообщений, пользовательскую проверку и побайтовую проверку истории после отката. Границы этого результата и проверки нового выпуска перечислены в [VALIDATION.md](docs/VALIDATION.md).

## Разработка и сборка

Нужны Windows x64, доверенный Python 3.12 и штатный C# compiler .NET Framework 4.x. Установка зависимостей через pip не требуется.

```powershell
python scripts/build_release.py --output output/build-0.1.40-beta.1
$env:REHOME_TEST_DECODER=(Resolve-Path output/build-0.1.40-beta.1/build-tools/libzstd.dll).Path
python scripts/run_tests.py
```

Сборщик получает Python и zstd из закреплённых публичных поставок, проверяет SHA256 и сравнивает каждый включённый PE-файл с исходной поставкой. Пользовательские профили, установленный Codex и прежние частные результаты сборки не читаются. Код Codex в комплект не включается. Пустые схемы строятся заново из `resources/schema-spec.json` и проверяются перед упаковкой.

Результат — `ReHome-0.1.40-beta.1-windows-x64.zip`, `SHA256SUMS.txt` и `build-info.json`. Каждая сборка получает собственный идентификатор и контрольные суммы; побайтовая воспроизводимость между сборками не обещается. Подробности — [BUILD.md](docs/BUILD.md).
