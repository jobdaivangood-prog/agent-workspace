# Agent Workspace — установка и работа

Комплект для Windows x64. Программа MCP — версия __VERSION__.

Agent Workspace сохраняет краткое состояние задач, решения и готовые результаты в общей папке. Через Synology Drive вы получаете эти данные на другом ПК и продолжаете работу с последнего принятого состояния.

## Что лежит в папке

1. **0_Описание.rtf** — этот документ.
2. **1_Установка_агента.md** — передать в Codex для добавления правил и команд.
3. **2_Установка_MCP.md** — передать в Codex для установки и подключения программы.

Папка **MCP** содержит готовый пакет и технический паспорт ainfo. Открывать её для обычной установки не требуется. Программа Codex и Synology Drive должны быть уже установлены. «Установка агента» здесь означает настройку правил уже установленного Codex.

## Шаг 1. Настроить агента

Перетащите файл [1_Установка_агента.md](1_Установка_агента.md) в чат Codex. Напишите:

> Установи правила агента по приложенной инструкции.

Агент сохранит резервную копию и добавит команды «Начни работу» и «Закончи работу». Остальные правила сохраняются. На этом шаге MCP ещё не подключается.

## Шаг 2. Установить MCP

Передайте в тот же чат файл [2_Установка_MCP.md](2_Установка_MCP.md). Напишите:

> Установи MCP Agent Workspace по приложенной инструкции. Папка комплекта: укажу её при необходимости.

Агент проверит готовый пакет, сам распакует программу локально и настроит подключение. В окне выбора папки укажите существующую синхронизированную **AI-Workspace**, внутри которой лежит workspace.json. Дождитесь её загрузки Synology Drive заранее. Если корректное подключение уже настроено, оно будет использовано без повторного выбора папки.

Один раз перезапустите Codex после завершения обоих шагов. Напишите: **«Проверь MCP Agent Workspace»**. Нужно проверить инструменты в самом чате и состояние базы.

## Как работать

**«Начни работу»** — проверить версии, загрузить принятое состояние задачи и выбранные готовые файлы. Можно уточнить: «Начни работу по проекту …».

**«Закончи работу»** — проверить все доступные чаты Codex, включая архив, и сохранить отдельные записи продолжения только для изменившихся чатов: итоги, решения и основания, уверенность, проверки, текущий этап, незавершённые вопросы и следующие шаги. Выбранные готовые результаты связываются с задачей.

**«Закончи работу только этот чат»** — выполнить сохранение только для текущего чата.

Неизменившиеся чаты не переписываются. Программа хранит ID последнего обработанного шага/сообщения и контрольную сумму. Повторная проверка сначала читает хвост, при изменении — прирост до сохранённой границы. Полную переписку каждый раз читать не требуется. При потере границы нужно дополнительное сравнение; раннее редактирование до неизменившейся границы может потребовать полной проверки.

Сводки формирует агент. Полные переписки и скрытые рассуждения не копируются в общую базу. Работающие или недоступные чаты перечисляются как ожидающие; сводки с неполным чтением отмечаются отдельно. История на другом ПК обрабатывается там при запуске процедуры.

Если версии расходятся, агент покажет сравнение и дождётся вашего выбора. Завершение сессии не означает завершение всей задачи. Исходники проектов остаются локально.

Доставку файлов между ПК выполняет Synology Drive. Таймера и сохранения при закрытии окна нет. Успешная запись в общую папку ещё не подтверждает доставку на NAS и другой ПК.

Технические подробности и ссылки на код — [MCP/ainfo.md](MCP/ainfo.md). История подключения первого ПК оставлена в материалах разработки: для установки она не требуется. Полный цикл на втором физическом ПК ещё предстоит проверить.
