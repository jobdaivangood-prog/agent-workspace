# Установка и подключение

Рекомендуемый готовый комплект — `Agent-Workspace-Setup.zip`. После полной распаковки пользователь видит описание RTF, файл настройки агента и файл установки MCP. Файлы по очереди прикладываются в Codex с прямым поручением выполнить соответствующий шаг. Внутреннюю распаковку и настройку путей выполняет агент.

## Разделение компонентов

- Codex устанавливается пользователем отдельно.
- «Настройка агента» добавляет только управляемый блок в активный пользовательский AGENTS.override.md/AGENTS.md с резервной копией и сохранением остальных правил.
- MCP — локальная программа, которую клиент запускает по stdio. Node.js уже находится в готовом Windows x64 пакете.
- Общая `AI-Workspace` — отдельная существующая синхронизируемая база с workspace.json. Установочная папка её не заменяет.

## Первый запуск

Агент проверяет SHA-256 готового ZIP и список файлов, распаковывает пакет в новый локальный каталог, сверяет его манифест и размещает программу локально. Если корректное подключение уже существует, оно используется без повторного выбора папки.

Для первого подключения установленный FolderPicker.exe показывает стандартное окно. Пользователь выбирает существующую базу. Агент проверяет workspace.json до вызова `attach`; пустая папка не создаёт новую базу. Отмена прекращает зависимые шаги.

В config.toml добавляется только одно подключение с реальными абсолютными путями данного ПК:

```toml
[mcp_servers.agent-workspace]
command = "ABSOLUTE_APP_DIR/runtime/node.exe"
args = ["ABSOLUTE_APP_DIR/app.mjs", "serve", "--local", "ABSOLUTE_LOCAL_STATE"]
```

Значения ABSOLUTE_APP_DIR и ABSOLUTE_LOCAL_STATE необходимо заменить реальными путями: это не автоматически раскрываемые переменные Codex. Остальные настройки должны сохраниться. Предварительно сохраняются исходные байты, при записи проверяется отсутствие конкурентного изменения.

После установки проверяются initialize → notifications/initialized → tools/list → workspace_startup. Ожидается 10 инструментов. Проверка конфигурации через `codex mcp get` сама по себе не проверяет запуск сервера. После обоих шагов перезапустите Codex и проверьте новый инструмент в чате.

## Ручное подключение готового runtime

`Setup.cmd` позволяет выбрать папку и подключить/создать базу, но не регистрирует MCP в Codex. Для переноса уже существующей базы предпочтительна команда `attach --root PATH --local LOCAL_STATE`, поскольку она не создаёт новую базу при ошибочном выборе пустой папки.

Команды «Начни работу» и «Закончи работу» выполняет агент по инструкциям; отдельной фоновой службы для них нет. Полные правила находятся в шаблонах packaging/simple. Само прикрепление файла не заменяет поручение пользователя выполнить установку.

Официальные источники: https://learn.chatgpt.com/docs/extend/mcp?surface=cli и https://learn.chatgpt.com/docs/agent-configuration/agents-md.
