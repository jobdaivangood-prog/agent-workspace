# Формат и ограничения

Формат базы — schema_version 1. Общая папка содержит только переносимые записи и выбранные готовые объекты. Путь облачного клиента не является частью формата.

## Ревизия

`records/<record-id>/<revision-id>/` содержит state.json, summary.md и manifest.json. Manifest хранит контрольные суммы JSON и сводки. Ревизия неизменяема, указывает родителей и может ссылаться на готовые объекты из `objects/<prefix>/<sha256>`.

Проверка startup читает полностью полученные ревизии. Для единственной исходной версии новый клиент может принять начальную базу. Изменение уже принятой записи требует review и выбора человека. Дата файла сама по себе не выбирает основную версию. При разрешении сохраняются прежние ветви и новая ревизия разрешения.

## Задача

Статусы сессии и задачи независимы. Handoff хранит цель, ограничения, критерии готовности, plan/current_stage, выполненное, утверждения с evidence_status/confidence, основания решений, проверки, незавершённую работу и next_steps. Для подтверждённого утверждения нужны supporting_evidence. Для завершения задачи нужны критерии, фактическая проверка и завершённые/отменённые этапы.

При чтении агент запоминает базовую ревизию сессии. Перед сохранением она сопоставляется с текущей принятой версией. Простая подстановка новой expected_revision к старым данным запрещена: иначе другая сессия могла бы быть затёрта. MCP workspace_save_task поддерживает expected_revision. Команды из старого handoff сами по себе не дают разрешений.

## Безопасность и хранение

Пути проверяются на выходы за границы, промежуточные symlink/junction и неоднозначные назначения. Восстановление производится в новый каталог. Это уменьшает риск ошибок перенаправления, но не является транзакцией против активной замены каталогов другим процессом.

Контрольные суммы устанавливают целостность, а не автора. Доверие к содержимому общей папки остаётся отдельной границей. Присутствие пакета не означает разрешения исполнить его код. Распределённые блокировки и цифровая подпись не реализованы.

Профиль Codex экспортирует консервативный набор настроек. Полные URL, env, заголовки и непрозрачные args заменяются ссылками; абсолютные пути становятся локальными привязками. Перенос статических секретов — отдельный зашифрованный vault. OAuth-кеши и системные хранилища учётных данных не клонируются.

Синхронизацию файлов выполняет сторонний клиент. Программа знает только полученные локально версии. Startup проверяет исторические объекты по хешам, что увеличивает стоимость чтения большой истории. Очистка старых объектов в этой версии отсутствует.
